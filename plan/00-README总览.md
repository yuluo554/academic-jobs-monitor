# 10-15-academic-jobs-monitor 项目计划总览

**项目**：高校学术招聘聚合监控器（多源抓取适配器 + 结构化字段抽取 + 快照与变更检测 + 订阅推送 + 内置基准；本地 Web 面板 + CLI 双形态）
**方法论**：ai-tool-project-sprint（多源适配器 + 确定性规则抽取 + 持久快照 diff + 真值基准 + 数据管道交付）
**项目系列**：同系列题（不参赛，发 GitHub 公开仓库）
**命名约定**：本地目录 `10-15-academic-jobs-monitor`（`10-15` = 2026-10-15 日期标签）；**GitHub 仓库名 = `academic-jobs-monitor`（纯净名，去日期前缀）**，沿用系列惯例 `yuluo554/<kebab-name>`；署名 `yuluo554`。
**定位宣言（v1）**：招聘信息散落在几十个人事处页面上且截止日期埋在正文里——本工具做多源聚合 + 结构化字段抽取 + 变更/截止监控推送（RSS/邮件），把"盯官网"变成可复现的数据管道。持久快照与变更历史是 LLM 聊天给不了的。
