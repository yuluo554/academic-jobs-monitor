3. **禁止事项**：不得虚构真实院校的待遇数值或截止日期；不得将推断值冒充标注真值；不采集个人信息（联系人姓名/电话不入字段库）；
4. **缓存边界**：仅缓存公开公告元数据（标题/URL/日期/正文抽取字段），不存整页镜像。
